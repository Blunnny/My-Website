# 前言

《浅薄》一书是美国作家尼古拉斯·卡尔出版于2010年的著作，作者站在互联网兴起的时间点，通过对历史、社会学、生物学等多个方面的研究，论证了互联网的出现对人们深度思考能力的毒害，这也是书名“浅薄”的由来。

今天重读这本书，我们不仅会看到，作者对于互联网影响的种种预言，在今天大多都以各种形式得到应验，而且还会发现惊奇地发现，某种程度上这些分析也适用于今天的人工智能。

在今天这个时间点，在人工智能已经渗透进人们生活的方方面面，甚至攻克多个前沿数学猜想的时刻，我们不妨通过本书，重温多年前的互联网浪潮对人们思想的影响，从中获取一些人工智能对未来影响的启发。

# 深度思考从何而来

自互联网流行以来，“上网有害学习”、“上网会形成碎片化认知”等等观点就开始广为传播。到了今天，这些观点几乎已经成为了常识，没有再去讨论的必要。

然而，这种观点默认了一个前提，即人们之前拥有着深度思考的能力，互联网的出现只是带走了人们的这种能力。而一个很少有人关注的问题是：**人们所谓深度思考的能力，真的是与生俱来的吗？**

在这里，其实有一个相当反直觉的观点：**碎片化认知才是人类的本性**，深度思考仅仅只是短暂出现于生活在过去几百年世界的人类中。实际上，人类今天引以为傲的深度思考能力，很大程度上只不过是印刷技术及其制品兴起的结果。

在印刷术广为传播之前，只有极少数的人，例如学者、猎人、工匠或是僧侣，会专门培养出持续集中注意力的能力，多数人每天接受的信息大多都来自与他人的交谈，这些信息本身就是相当碎片化的。

是在书籍成为知识与信息最主要的获取方式之后，人们才开始被迫地适应这种注意力高度集中的状态——不仅要理解当前语句的含义，还要将其放到相当长的上下文中进行理解，甚至还要在此基础上展开联想、进行推论，乃至形成自己的思想。正是通过这样经年累月的训练，人们才终于获得了深度思考的能力。

因此，与其说互联网破坏了人们的思考能力，不如说互联网不过是迎合了人类的本性，把人类带回了那个书籍出现之前的原始状态。

# 互联网如何瓦解深度思考

如果深度思考只是印刷术的副产品，那么它的瓦解似乎不值得惋惜。但问题在于：印刷术训练出的深度思考能力，恰恰是科学、哲学、文学这些文明成果的认知基础。

而互联网也不只是“回到原始状态”，它用一套新的组织方式，把碎片化推向了印刷术之前从未有过的强度——人们开始变得越来越浮躁，再也无法沉浸于一部文学作品精巧的构思，而只是想不断获得短平快的刺激。

究其根源，**互联网这一信息的组织形式，本身就不适宜人们进行深度的思考**。

由于互联网充满着无数的跳转链接与无穷无尽的信息流，上网这一行为本身，就要求人们需要具备较高的并发处理多重任务的能力。相比于传统读书，这种多任务的认知方式不仅极大地增加了人们的认知负荷，而且还会给我们的认知过程增加脑科学家所说的"切换成本"，每次转移注意力，我们的大脑都得进行自我调节，从而进一步加大了脑力资源的损耗。

尽管这种多任务的认知方式也有一定的好处，例如让我们的大脑在遇到多重任务的时候更加敏捷，但多任务处理能力的改进实际上会损害深入思考和创新思考的能力。同时处理的任务越多，我们就倾向于更轻率地处理任务，思考和解决问题的能力就越差，人们变得更加依赖常规思想和传统办法，而不是以原创性思维解决问题。

[互联网、流量与商业——互联网变现逻辑](/blogs/essays/Internet-Monetization-Logic)中曾经提到过，对于互联网行业的公司来说“流量即货币”，吸引更多用户的更多注意力就等价于更高的收入，而结合上面讨论的互联网对人们注意力的瓦解作用，我们就能得到今天互联网的一个最大的悖论——**互联网吸引我们的注意力，只是为了瓦解我们的注意力**。

# 瓦解之外

除了对注意力的影响，关于互联网带来的虚拟世界，同样曾经引发过无数的讨论。人们通常划分为两个阵营：一派欣喜于互联网所创造的平等的世界，为所有人都能参与其中的“新黄金时代”的到来而欢呼，另一派则为充斥着牛鬼蛇神、自我陶醉的黑暗时代的开始而悲叹。

两派争论的焦点都在互联网所带来的内容，但真正的问题其实不在内容层面，因为无论内容好坏，只要人们是在屏幕、链接和信息流的结构中接触内容，这种接触方式本身就在训练一种特定的注意力模式——而注意力模式比任何具体观点都更根本。因此，**从长远看，互联网本身比它传播的内容更重要**。

我们总是喜欢宣称技术本身无关紧要，告诉自己真正重要的是如何使用技术。实际上，这是一种非常狂妄自大的思想，而在这种思想背后隐含的意思是：**我们仍然掌控一切，技术只是工具**——在我们拿起工具之前，它们不会起任何作用；而在我们放下工具之后，它们又会归于沉寂。

然而，神经可塑性告诉我们：人用以拓展自己神经系统的工具，也反过来塑造了人脑的物理结构和工作方式。

我们怎样发现、储存、解释信息，怎样引导注意力，怎样回忆和忘记，都受到技术的影响。当我们握着锤子的时候，手能做的只有锤子能做的事。最终，**技术成为人的外延，人也成了技术的外延**。

# 从互联网到人工智能

如果说十多年前的互联网是通过“碎片化”瓦解了深度思考的过程，那么今天的人工智能，则是直接接管了深度思考的结果。

互联网时代，我们至少还在信息流中疲于奔命地进行筛选与拼接，而在生成式人工智能面前，连这种费力的过程也被彻底省去了——阅读长文变成了一键总结，构思框架变成了指令生成，推演论证变成了直接索取答案。

深度思考原本是一种需要阻力、需要忍受枯燥与困惑的“高摩擦”活动——正如印刷术时代人们在长篇累牍的字句中经年累月地训练大脑一样。正是思考过程中的阻力，塑造了我们的认知能力，而人工智能最迷人、也最危险的地方，恰恰在于它抹平了几乎所有的认知阻力。

当思考的门槛被降到最低，人类便会本能地选择“认知外包”。如果说互联网时代的“浅薄”还需要人们主动跳进信息流，那么AI时代的“浅薄”就只需要人们放弃抵抗。工具不再只是延伸我们的手脚，也不再只是切割我们的时间，而是直接替代我们的推演、判断与表达。

当工具不仅在塑造大脑，甚至开始接管大脑最核心的功能时，那个原本属于未来的问题，便摆在了我们面前：在一切都可以被算法模拟和替代之后，人还剩下什么不可被替代的部分？

# 何以为人

魏泽鲍姆在其 1976 年出版的《计算机的力量与人类的理性》中曾经提到，把计算机引入某些复杂的人类活动，会让我们的智力与社会生活变得和工业流程一样，逐渐成为计算机强加给我们的种种形式的反映。在我们跟计算机变得越来越密不可分的过程中，我们越来越多的人生体验通过电脑屏幕上闪烁摇曳、虚无缥缈的符号完成。 

计算机将逐步成为定义人们日常生活中种种活动的仲裁者，决定我们怎样学习，怎样思考，怎样进行社会活动。

魏泽鲍姆也同时相信，人之所以为人，恰恰就在于人那些最不可能计算机化的部分，像是我们的思想和身体之间的联系，塑造我们记忆和思维的经验，以及我们具有丰富情感的能力，而最大的危险，正是我们即将开始丧失我们的人性，丧失人之所以区别于机器的本质属性。

我们大脑的适应能力，是固化在大脑工作机理中的规律，也是智力发展史的基调。适应能力让我们更好地适应自己所处的环境，但在性质上是一个中立的过程。到头来，**真正重要的不是我们正在改变什么，而是我们变成了什么**。

技术带来的诱惑难以抵挡，身处在这样一个时代，对速度和效率的追求几乎是不容置疑、无可争辩的。不过，我们还是可以继续抱有希望——希望我们不会在追求效率的过程中，把深度思考能力变成一种稀缺品。
